# Codebase Structure

**Analysis Date:** 2026-08-25

## Directory Layout

```
[project-root]/
├── .agent/             # AI agent workflows and custom actions
│   └── workflows/      # Multi-step instructions for tasks
├── assets/             # Branding assets, screenshots, and visual designs
├── dist/               # Production compile output (generated by vite build)
│   └── assets/         # Bundled JS, CSS, and images
├── public/             # Static assets copied directly to root on build
├── src/                # Core application source code
│   ├── components/     # UI presentation components
│   ├── data/           # Local static data and simulation payloads
│   ├── App.tsx         # Main application shell and routing orchestrator
│   ├── index.css       # Core Tailwind CSS imports and utility classes
│   ├── main.tsx        # Mounts the React virtual DOM tree
│   └── types.ts        # TypeScript interface mappings
├── index.html          # HTML entry point template
├── package.json        # Dependencies and build script specifications
├── tsconfig.json       # TypeScript compilation preferences
└── vite.config.ts      # Vite configuration for plugins and aliases
```

## Directory Purposes

**src/components/**
- Purpose: Presentational and interactive React layout components.
- Contains: `*.tsx` React files. Each file represents a section of the single-page application (e.g. Hero, About, Services) or overlay modals.
- Key files:
  - `Navbar.tsx` - Floating navigation and theme switcher.
  - `LabSection.tsx` - Interactive client-side mock tools and visualizers.
  - `ProjectEstimatorModal.tsx` - Step-by-step price and scope calculator.
  - `ClientPortalModal.tsx` - Simulated developer tracker portal.

**src/data/**
- Purpose: Single source of truth for mock data, services details, and lab configs.
- Contains: `companyData.ts` file containing mock datasets.
- Key files:
  - `companyData.ts` - All project descriptions, testimonials, metrics, and pricing formulas.

**dist/**
- Purpose: Contains static, minified bundle files compiled for web server deployment.
- Contains: Compressed `.js`, `.css` assets, images, and HTML.
- Source: Created by running `npm run build`. Not committed (gitignored).

**.agent/workflows/**
- Purpose: Agent guidelines and workflows.
- Contains: `.md` files matching slash-command workflows.
- Key files: `map-codebase.md`, `audit.md`, `polish.md`.

## Key File Locations

**Entry Points:**
- `index.html` - HTML skeleton loading the main TSX module.
- `src/main.tsx` - Boots React virtual DOM and mounts `<App />` into the DOM node.
- `src/App.tsx` - Orchestrates active views, loading screen, modal visibility, and theme styling class applications.

**Configuration:**
- `package.json` - Defines project metadata, build scripts, development tools, and package versions.
- `vite.config.ts` - Registers React plugins, Tailwind CSS directives, and compiler resolution path mappings (`@/` points to root).
- `tsconfig.json` - Configures strict TypeScript checks and module configurations.
- `.env.example` - Public outline of environment variables.

**Core Logic:**
- `src/components/LabSection.tsx` - Houses client-side scripting logic for the Webhook payload parsed SQL generator and simulated latency.

## Naming Conventions

**Files:**
- PascalCase.tsx for React components (e.g. `FeaturedWorkSection.tsx`).
- camelCase.ts for files containing helper scripts, configuration data, or types (e.g. `companyData.ts`, `types.ts`).
- lowercase.config.ts for environment configs (e.g. `vite.config.ts`).

**Directories:**
- camelCase or kebab-case for system folders (e.g. `src/components`, `.agent/workflows`).

## Where to Add New Code

**New Section / Interactive Component:**
- Implementation: Create a TSX component inside `src/components/` (use PascalCase).
- Data Integration: Update mock lists in `src/data/companyData.ts` if section requires backing data.
- Layout Injection: Import and place inside `<main>` routing container inside `src/App.tsx`.

**New Data / Configuration:**
- Definition: Define interfaces in `src/types.ts`.
- Content: Add objects/records inside `src/data/companyData.ts`.

**Styling / Animation Classes:**
- Rules: Add custom utilities, extends, or keyframe animations inside `src/index.css` inside the appropriate layer (e.g., `@layer base`).

## Special Directories

**node_modules/**
- Purpose: Contains downloaded third-party packages.
- Committed: No (gitignored).

**dist/**
- Purpose: Compiled build folder for static hosting.
- Committed: No (gitignored).
